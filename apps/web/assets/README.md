# Browser assets

`gantiin-logo.svg` is the owner's original transparent Ribbon logo, retained unchanged.

`login-finance-hd.png` is the approved 1536 x 1024 blue finance illustration reconstructed from the owner's small reference image using image generation. Reconstructed details are generated; they are not recovered information from the low-resolution source. The same static file is reused for the login photo panel and faint background. The panel is hidden on narrow screens.

`paypal-mark.svg` is the official PayPal colour mark, sourced from https://www.paypalobjects.com/paypal-ui/logos/svg/paypal-mark-color.svg and stored locally for the login control. PayPal trademarks remain their owner's property; the project does not claim ownership or endorsement.

The server serves exact allowlisted asset paths. Do not expose private images, uploads, runtime receipts or Downloads directories as static files.
