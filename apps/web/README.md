# Template web

Belum ada aplikasi atau dependency. Next.js/TypeScript hanya usulan.

## Folder

- src/components: komponen bersama.
- src/features: alur acara, pengajuan, tinjauan, pembayaran, laporan.
- src/lib: akses API dan utilitas tampilan.

Satu tampilan panitia dipakai banyak akun; data mengikuti pengguna. API tetap menegakkan pembatasan sebenarnya.

Jangan simpan secret pada browser. Visual direction belum dipilih. Saat implementasi diizinkan, tentukan arah bersama pemilik dan sediakan keadaan kosong, memuat, gagal, serta akses keyboard.
