# Product brief

Gantiin lets each committee member submit a mixed receipt and purchase context. AI accepts/rejects each item using versioned event policy and labeled Google Sheets references. The server calculates MYR sen and automatically pays eligible expenses through PayPal Sandbox, capped at available budget. Successful payments update Sheets. The treasurer configures the event, creates CMTs, and reads history, without manual approvals or overrides.

Problem hypotheses and accuracy/time savings are unmeasured. Receipt authenticity is not certified. Final event remains unselected. PRD 1.1 defines scope; PROJECT_STATUS.md and docs/verification.md record actual implementation evidence.
