# Interface system

The authoritative visual specification is [DESIGN.md](../../DESIGN.md). Its 12 November blue/navy finance-photo design supersedes the earlier rose/glass palette.

Use existing native HTML controls and CSS tokens in apps/web/style.css. Preserve the original logo, mobile Menu, desktop collapsed rail, nested Settings, visible focus, 44px controls and reduced-motion support. Financial status must come from backend evidence, including confirmed payment rather than eligibility.

The regression suite checks text contrast, control borders, keyboard/focus paths, responsive overflow, history filters, native dialogs and isolated demo data. Test screenshots are ignored local artefacts, not source assets. See [current verification](../verification/current.md).
