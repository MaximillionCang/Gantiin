Actual paid amounts depend on the real spreadsheet balance. This package does not initialise or add funds to Google Sheets, change the active saved event, enable AI usage or trigger a payout. The receipt images target the real OCR/Decider path; the old fixed-fixture reader does not infer unseen images.
