# Template evaluasi

Belum ada evaluasi atau label yang dihasilkan. cases.csv hanya format pencatatan.

Siapkan kasus bon campuran, barang sama dengan konteks berbeda, singkatan, foto buram, aturan kurang, batas nominal, instruksi berbahaya dalam bon, dan duplikasi.

Label manusia mengacu pada policy version yang jelas. Jangan menjadikan jawaban model yang diuji sebagai ground truth.

Pisahkan data berdasarkan bon asal dan acara; varian crop/edit tidak melintasi pembagian. Catat salah lolos, salah tolak, kebutuhan review, rujukan aturan, ketepatan OCR, latency, dan biaya. Bandingkan baseline dan fine-tuned pada test terpisah.
