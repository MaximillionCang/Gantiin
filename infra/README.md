# Template infrastructure

Belum ada deployment, container, resource cloud, atau konfigurasi executable.

Gunakan folder ini nanti untuk konfigurasi yang dapat direproduksi. Secret tetap di pengaturan lingkungan/secret manager.

Rencanakan web/API, database, private storage, model worker, notifikasi PayPal, retensi, backup, akses juri, dan biaya saat compute berhenti.

Lihat [deployment](../docs/operations/deployment.md).
